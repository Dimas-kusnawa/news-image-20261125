A program that writes one image summing up Wednesday, 25 November 2026's world news to `/output/entry.png`: a newspaper front page dated 25 November 2026. Lead story: the CIA and ODNI hit by a cyberattack. Also covered: Ukraine sinking a Russian ship off Libya, the Huawei guilty verdict, the Houthi drone strike on Riyadh's tallest tower, the WHO evacuation of Ebola staff in DR Congo, and President Trump pardoning the Thanksgiving turkeys Freedom and Feathers. The image is a whole PNG, 1024 by 1024 pixels, under 1 MiB, and the program copies it byte for byte, so both runs write identical output.

## Run it

```sh
python3 main.py
```
